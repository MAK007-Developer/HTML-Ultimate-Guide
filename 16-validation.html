    15 senior-level best practices

    1. Semantic HTML first. Choose the right element before you choose a class.
    2. Validate every page. The parser tolerates errors; the accessibility tree does not.
    3. Progressive enhancement. The page should work before JS loads.
    4. Exactly one h1 per page, matching the page's purpose.
    5. Always set alt, width and height on images.
    6. Every input has a label and a name. No exceptions.
    7. Every button has a type. type="button" for non-submit actions.
    8. Native elements over ARIA. ARIA fixes gaps; it does not replace semantics.
    9. Use <dialog> for modals. showModal() gives you focus trapping and ESC handling.
    10. Don't lazy-load the LCP image. fetchpriority="high" on the hero.
    11. Absolute URLs for SEO metadata. Open Graph, canonical, and JSON-LD all need absolute URLs.
    12. rel="noopener" on target="_blank". Even when the browser implies it.
    13. Set lang on <html>. Screen readers and translation rely on it.
    14. Ship a skip link. It is the cheapest accessibility win on any page.
    15. Treat the outline as a contract. Your heading tree is the page's table of contents for screen readers and crawlers.
