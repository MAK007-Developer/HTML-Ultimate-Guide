    Links & Navigation

    The element that makes the web a web — plus the path rules, security attributes and accessibility habits that go with it.

    The <a> element

    <!-- External -->
<a href="https://example.com" target="_blank" rel="noopener noreferrer">
  Visit Example (opens in a new tab)
</a>

<!-- Same-page fragment -->
<a href="#section-3">Jump to section 3</a>

<!-- Email — prefill subject and body -->
<a href="mailto:hello@example.com?subject=Hello&body=Hi%20there">Email us</a>

<!-- Phone -->
<a href="tel:+15551234567">+1 555 123 4567</a>

<!-- Download with a suggested filename -->
<a href="/files/report.pdf" download="annual-report-2026.pdf">Download the report</a>

<!-- Just a suggestion of a filename (cross-origin ignores it) -->
<a href="/files/data.csv" download>Download CSV</a>

    Path rules

    How an href resolves — current page is https://example.com/docs/guide/page.html
    TypeExampleResolves toUse when
    Absolutehttps://other.com/aExactly as writtenCross-origin links, canonical, OG tags.
    Root-relative/docs/introhttps://example.com/docs/introSame site, stable regardless of page depth.
    Relativesibling.html…/docs/guide/sibling.htmlNeighbouring files in the same folder.
    Parent../index.html…/docs/index.htmlGoing up one directory level.
    Fragment#pricingSame URL + #pricingIn-page navigation, skip links, TOC.
    Query?page=2Same path + query stringPagination, filters, tracking params.

    Link best practices

    <!-- ❌ A link that goes nowhere -->
<a href="#">Read more</a>
<a href="javascript:void(0)">Read more</a>

<!-- ✅ A real destination -->
<a href="/blog/responsive-images">Read “Responsive Images Explained”</a>

<!-- ❌ Non-descriptive link text (useless in a screen-reader link list) -->
<a href="/report">Click here</a>

<!-- ✅ Descriptive -->
<a href="/report">Download the 2026 annual report (PDF, 4 MB)</a>

<!-- ✅ Cross-origin links opened in a new tab -->
<a href="https://external.example" target="_blank" rel="noopener noreferrer">
  External resource
</a>

<!-- ✅ Indicate the current page inside a nav -->
<nav aria-label="Main">
  <ul>
    <li><a href="/">Home</a></li>
    <li><a href="/docs" aria-current="page">Docs</a></li>
    <li><a href="/pricing">Pricing</a></li>
  </ul>
</nav>
    !

    rel="noopener" stops the opened page from accessing window.opener (a reverse-tabnabbing vector). Modern browsers imply it for target="_blank", but writing it explicitly is still correct and protects older engines. noreferrer additionally strips the Referer header.

    Fragment navigation and skip links

    <!-- Put the skip link first inside <body> -->
<a class="skip-link" href="#main">Skip to main content</a>

<header> … navigation … </header>

<!-- tabindex="-1" makes the target programmatically focusable,
     so keyboard focus actually moves there in every browser. -->
<main id="main" tabindex="-1">
  <h1>Page title</h1>
</main>

<!-- Any element with an id is a fragment target -->
<h2 id="pricing">Pricing</h2>
<a href="#pricing">See pricing</a>

     usemap="#floorplan" width="800" height="600">

<map name="floorplan">

  <area shape="circle" coords="400,300,60"    href="/rooms/bath"    alt="Bathroom">
  <area shape="poly"   coords="500,100,600,120,560,220" href="/rooms/study" alt="Study">
</map>
