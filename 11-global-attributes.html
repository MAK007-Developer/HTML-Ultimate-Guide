    Global Attributes

    Attributes available on every element — plus the custom-data escape hatch and the hidden/inert comparison.

    Full table

    Global attributes
    AttributePurposeNotes
    idUnique identifier within the documentMust be unique; used by labels, aria, fragments.
    classSpace-separated list of classesNo semantics; purely a styling/JS hook.
    styleInline CSS declarationsPrefer stylesheets; avoid for maintainability.
    titleAdvisory information (tooltip)Not a substitute for accessible names.
    langContent language (BCP 47 tag)Inherits; override for foreign-language passages.
    dirText direction: ltr / rtl / autoSet on <html> for whole-page RTL.
    hiddenHidden from rendering and ATDifferent from inert — see below.
    inertNon-interactive, unfocusable, invisible to ATGreat for offscreen drawers and modal backdrops.
    tabindexFocus order; -1 = programmatic onlyAvoid positive values; they break tab order.
    contenteditableMakes the element editableRarely the right answer; build a real editor.
    draggableWhether the element can be draggedMust be paired with dragstart/dragover handlers.
    spellcheckToggle spell checkingtrue / false
    translateWhether to translate the contentUse translate="no" on brand names.
    autofocusFocus the element on page loadOne per page; can steal focus from AT users.
    accesskeyKeyboard shortcut hintPoorly supported; avoid in public UIs.
    data-*Custom data attributesExposed via element.dataset.
    slotAssigns a child to a named slotUsed inside shadow DOM.
    partExposes a shadow-DOM element to ::part()Style from the outside without piercing.
    nonceCSP nonce for inline scripts/stylesMust match the server's CSP nonce.

    data-* attributes

    <button data-action="delete" data-id="42" data-confirm>Delete</button>

<script>
  const btn = document.querySelector("[data-action='delete']");
  console.log(btn.dataset.action);   // "delete"
  console.log(btn.dataset.id);       // "42"
  console.log(btn.dataset.confirm);  // "" (present but empty)
  btn.dataset.confirm = "true";      // sets data-confirm="true"
  delete btn.dataset.confirm;        // removes the attribute
</script>

<!-- Naming rules: data-* must be lowercase, hyphens allowed.
     dataset converts kebab-case to camelCase:
       data-user-id  →  dataset.userId
     Never put sensitive data here: it is visible in the DOM. -->

    hidden vs inert vs display:none

    Removing content from the page
    MechanismVisible?Focusable?In accessibility tree?Space reserved?
    hiddenNoNoNoNo
    inertYes (unless also hidden)NoNo (subtree)Yes
    display:noneNoNoNoNo
    visibility:hiddenNoNoNoYes
    aria-hidden="true"YesYesNoYes
    ✔

    Use inert on the rest of the page while a modal is open. Use hidden for content that shouldn't exist on the page. Use display:none via CSS when you want it styled by CSS but removed from layout.
