    SEO, Social & Structured Data

    The handful of HTML strings that influence search ranking, sharing previews, and rich results.

    On-page essentials

    <!-- Every page needs a unique, descriptive title. -->
<title>Responsive Images Explained — Acme Docs</title>

<!-- The description is what shows under the title in search results. -->
<meta name="description" content="How srcset, sizes and picture work, with copy-paste examples.">

<!-- Canonical: the authoritative URL for this content. -->
<link rel="canonical" href="https://example.com/docs/responsive-images">

<!-- One H1 that matches the page's purpose. -->
<h1>Responsive images, explained</h1>

    Crawling control

    <!-- Allow indexing (default) -->
<meta name="robots" content="index, follow">

<!-- Do not index this page -->
<meta name="robots" content="noindex, follow">

<!-- Do not follow links -->
<meta name="robots" content="noindex, nofollow">

<!-- Tell crawlers a different canonical URL (cross-domain) -->
<link rel="canonical" href="https://canonical.example/page">

<!-- robots.txt (server file, not HTML):
     User-agent: *
     Disallow: /admin/
     Sitemap: https://example.com/sitemap.xml -->
    !

    noindex vs robots.txt: noindex keeps a page out of the index but allows it to be crawled. robots.txt blocks crawling entirely — which means a crawler can never see your noindex tag. Use noindex to remove a page from results; use robots.txt to protect a private path.

    Open Graph + Twitter Cards

    <!-- Open Graph: used by Facebook, LinkedIn, Slack, Discord, iMessage. -->
<meta property="og:type" content="article">
<meta property="og:title" content="Responsive Images Explained">
<meta property="og:description" content="How srcset, sizes and picture work.">
<meta property="og:image" content="https://example.com/og/responsive-images.png">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:url" content="https://example.com/docs/responsive-images">
<meta property="og:site_name" content="Acme Docs">

<!-- Twitter / X cards -->
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="Responsive Images Explained">
<meta name="twitter:description" content="How srcset, sizes and picture work.">
<meta name="twitter:image" content="https://example.com/og/responsive-images.png">

<!-- og:image MUST be an absolute URL — relative paths are ignored.
     Recommended size: 1200×630 (1.91:1). -->

    Semantic HTML is SEO

    • Search engines parse the same DOM a browser builds — valid, semantically meaningful HTML is parsed correctly.
    • Headings (h1–h6) tell crawlers what each block is about; skipped levels dilute the signal.
    • Descriptive link text gives crawlers context for outbound links.
    • Structured data (JSON-LD) unlocks rich results (star ratings, recipes, events, FAQs).
    • Fast, accessible pages rank better because Core Web Vitals are a ranking signal.
