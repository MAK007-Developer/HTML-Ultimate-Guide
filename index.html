    The Complete HTML Guide

    From first principles to advanced modern markup. This guide is split into one page per topic — use the sidebar, the cards below, or the previous / next links on each page. Every page includes copy-paste code examples and the reasoning behind the rules.

    ✔

    How to use this guide. Read it top to bottom once, then keep it open as a checklist. Each page is self-contained, so you can jump straight to Forms, Accessibility or Performance when you need them. All 20 files must sit in the same folder.

    How the pages are organised

    • Pages 1–4 build the mental model: what HTML is, how a document is structured, text content, and links.
    • Pages 5–7 cover the visual building blocks: images, media, lists and tables.
    • Page 8 is the deep dive on forms — the longest section.
    • Pages 9–11 cover semantics, interactive elements and global attributes.
    • Pages 12–16 are about quality: accessibility, SEO, performance, advanced APIs, and validation.
    • Appendix is a symptom → cause lookup table for the bugs you will actually hit.
